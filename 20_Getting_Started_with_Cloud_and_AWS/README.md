## 1단계 - 클라우드 및 AWS 소개 - 장점

#### 클라우드
인터넷을 통해 접근할 수 있는 서버, 소프트웨어, 데이터베이스 및 다양한 컴퓨팅 리소스의 네트워크

#### 클라우드 서비스
컴퓨팅 리소스 네트워크 임대 서비스
- 자본 비용을 가변 비용으로 바꿀 수 있다.
- 거대한 경제 규모로 혜택을 볼 수 있다.
- 데이터 센터가 필요 없다.

#### 클라우드 서비스의 장점
- 유연성: 필요에 따라 리소스를 확장하거나 축소할 수 있다.
- 비용 효율성: 사용한 만큼만 비용을 지불하는 모델을 제공.
- 접근성: 인터넷 연결만 있으면 어디서든 접근 가능.

#### 클라우드 서비스가 생기기 전에 발생하던 문제
- 낮은 인프라 가동률과 최대 부하에 대비한 인프라 마련
  - 클라우드가 없었을 때는 최대 부하를 예상하고 인프라를 마련할 수 밖에 없었다. ex) 구축 당시 고사양의 서버 NAS를 준비하는 등
  - 높은 비용을 지불하고 고사양의 인프라를 구축해도 서비스가 커지기 전까지 유휴 상태로 낭비되었다.
- 사전 계획 및 비용 필요
  - 최대 부하를 예측하는 일이 너무 어려웠다.
  - 인프라 유지 관리 팀이 필요했다.

#### 대표적인 클라우드 서비스 제공사
- AWS
- Azure 
- Google Cloud
- Oracle
